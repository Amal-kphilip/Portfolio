# Amal K Philip — Apps

Portfolio site showcasing my open source apps: Geekify App, Geekify, CleanShot and Framelet.

**Live site:** https://amal-apps.vercel.app

## Built with
Next.js, TypeScript, Tailwind CSS, Three.js, GSAP and Lenis.

## Run locally
Requires Node 20.9+.

    npm install
    npm run dev

Then open http://localhost:3000.
